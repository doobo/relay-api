API Configs (non-AI forwarding)

A name may end in /* (one more path segment) or /** (everything below it). The matched part is appended to the config URL: api/** + https://host/v1 → /open/api/users/1 forwards to https://host/v1/users/1.

Method None pins no upstream verb: whatever the client sends (GET, POST, …) is forwarded unchanged. Any other method replaces the client's verb on every call.

Route picks the mount point: /open/<name> requires an API key, /free/<name> is public and skips key validation, scope, quota and rate limiting. A config answers on its own mount only.

/open forwards request/response JSON bodies (templates apply, the method can be pinned). /free is a raw streaming tunnel: the client body and the upstream response are piped through unbuffered, so it can carry long-lived streaming protocols. Method, request/response templates are ignored there, and the stream timeout / stream body limit fields apply to /free only (0 = unlimited).
